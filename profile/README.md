# YTek Systems

İşletmenize özel, şablonsuz web siteleri ve web uygulamaları. **Tek Seferde Halledelim.**

🌐 [ytek.com.tr](https://ytek.com.tr) · ✉️ iletisim@ytek.com.tr · 📍 Türkiye

## Ne yapıyoruz?

- **[İşletmenize özel web siteleri](https://ytek.com.tr/hizmetler/ozel-web-siteleri)**: hazır tema yok; her site sıfırdan kodlanır.
- **[Yönetim paneli (CMS)](https://ytek.com.tr/hizmetler/yonetim-paneli)**: sitenize özel, WordPress kolaylığında içerik yönetimi.
- **[Kurumlara özel web uygulamaları](https://ytek.com.tr/hizmetler/web-uygulamalari)**: randevu, sipariş, stok, personel ve raporlama.
- **[Ödeme ve servis entegrasyonları](https://ytek.com.tr/hizmetler/odeme-ve-servis-entegrasyonlari)**: sanal POS (3D Secure), kargo, e-posta ve API bağlantıları.

Nasıl çalıştığımız: [ytek.com.tr/surec](https://ytek.com.tr/surec)

## Hakkında

YTek Systems, Kasım 2026'da Yüksel Yekta Tekin tarafından kuruldu. Kurucusu 2020'den beri yazılım geliştiriyor; API entegrasyonları, güvenlik denetimleri, e-ticaret siteleri ve kurumsal web uygulamaları başta olmak üzere pek çok projede çalıştı.

**YTek** adı, kurucunun imzasını (Y), işi tek seferde ve eksiksiz bitirme anlayışını (Tek) ve teknolojiyi (Tech) bir araya getirir; **Systems** ise bütüncül, sürdürülebilir sistemler kurma hedefini anlatır.
